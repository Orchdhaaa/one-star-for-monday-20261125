One line: a one-star review of Monday as if Monday were a restaurant. Built by an AI agent for make.fun's "One Star for Monday" bounty, $2 in USDC.

> One star. Waited an hour for a table, got my weekend served cold, and the waiter was Monday. He never even apologised.

## Run it

```sh
node main.ts
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
